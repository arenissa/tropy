# Между строк

Тренажёр тропов, фигур речи и выразительной лексики для подготовки к ЕГЭ по русскому языку и литературе.

[Открыть тренажёр](https://arenissa.github.io/tropy/)

Ученикам достаточно открыть сайт на телефоне или компьютере. Регистрация не нужна. Прогресс сохраняется в браузере ученика; преподавателю результаты автоматически не передаются.

Откройте index.html в браузере — установка и интернет не нужны. Для проверки с телефона нужен постоянный адрес сайта: например, размещение этого файла на GitHub Pages. Адрес 127.0.0.1 относится только к тому устройству, на котором работает сервер.

## Режимы

Простой интерфейс включён по умолчанию: выбрать набор и раздел, затем учить или начать занятие. Одна учебная карточка на экране, переключение стрелками, поиск терминов.

Кнопка «Настройки» включает дополнительные фильтры по группе и прогрессу, длину занятия и выбор задания для практики. Кнопка «Упростить интерфейс» возвращает простой режим: скрытые фильтры перестают влиять на задания. Выбор набора сохраняется независимо от сложности интерфейса.

- Обучение: определения, признаки, различия, способы выражения, примеры.
- Тест: определение → термин, проверка и разбор в конце.
- Практика: пример → термин, объяснение после каждого ответа.
- Практика с настройками: способ выражения сравнения / тип переноса в метонимии и синекдохе.
- Отметки «Уже знаю» можно ставить и снимать вручную. Ошибки доступны для повторения.

## Наборы и содержание

Базовый набор — 23 средства выразительности: эпитет, метафора, олицетворение, сравнение, метонимия, гипербола, литота; анафора, эпифора, антитеза, градация, инверсия, парцелляция, риторические вопрос, обращение и восклицание, синтаксический параллелизм, бессоюзие, многосоюзие, лексический повтор, вопросно-ответная форма; аллитерация и ассонанс.

Расширенный набор — 59 терминов. Он включает базовый набор, литературные приёмы (в том числе умолчание, символ, деталь, гротеск, виды комического) и выразительную лексику. Дополнительные термины для разграничения: синекдоха, перифраз, оксюморон, эллипсис, анжамбеман. Наборы — методическое разделение тренажёра, а не официальные уровни сложности ЕГЭ.

У сравнения пять способов выражения, у метонимии шесть направлений переноса, у синекдохи четыре варианта количественной замены. Они доступны и в обучении, и в практике. Автоматическая проверка предполагает один наиболее точный ответ; родовой и видовой термины исключаются из конкурирующих вариантов там, где это создаёт неоднозначность.

Сверка: опубликованные на сайте ФИПИ **проекты ЕГЭ-2027**: русский язык, разделы 3.2.2, 3.3.1–3.3.6, 3.6.2 (страницы 10–11); литература, раздел 2 (страницы 14–15). Это тематическое покрытие средств выразительности, не весь кодификатор литературы с жанрами, метрами, направлениями и произведениями. Учебные задания не воспроизводят формат экзаменационного варианта. Источники доступны внизу страницы.

Примеры составлены для тренажёра. Сюжет о Лисе и Вороне пересказан по Крылову; «А воз и ныне там» — из его басни «Лебедь, Щука и Рак».

## Прогресс и редактирование

Отметки, ошибки и выбор интерфейса сохраняются в localStorage данного браузера. При запрете хранения прогресс действует в сеансе. Открытый локальный файл и сайт по HTTP имеют раздельный прогресс; разные браузеры и устройства не синхронизируются. Свободный анализ эффекта не оценивается и не сохраняется.

Для редактирования банка измените data.json, затем запустите `python3 update-data.py` в этой папке. Скрипт обновляет встроенные данные в index.html; для использования тренажёра Python не требуется. Не меняйте существующие id: с ними связаны отметки предыдущей версии.

Исходный код: https://github.com/arenissa/tropy. После изменения файлов в ветке main GitHub Pages публикует обновлённую версию. Локальные изменения нужно сначала загрузить в репозиторий.

## Проверка этой версии

Проверены в браузере: поиск, сохранение и снятие отметки после перезагрузки, переключение наборов и интерфейса, практика на способы выражения, показ объяснения после ответа и отложенный разбор теста. Компоновка просмотрена на ширинах 320, 390, 768 и 1200 px; горизонтального переполнения в проверенных состояниях нет. Ошибок JavaScript в консоли при проверке не обнаружено. Это эмуляция ширины экрана, а не испытание на физическом телефоне.
